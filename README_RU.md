# Mobile Gateway — Android 0.1

Русскоязычное приложение для POCO X6 Pro / HyperOS.

## Возможности
- показывает тип активного подключения и статус проверки Android;
- проверяет DNS-разрешение нескольких контрольных доменов;
- показывает наличие IPv4 и IPv6 адресов;
- проверяет HTTPS HEAD-запросы и время ответа;
- формирует текстовый отчёт, которым можно поделиться.

Приложение не использует root, VPN или специальные права оператора. Это диагностический инструмент, а не средство снятия сетевых ограничений.

## Сборка
Требуются JDK 17, Android SDK Platform 35 и Gradle 8.9.
В Android Studio откройте папку проекта и выполните Build > Build APK(s).
